# Private Networks
IP addresses that are not routable through the internet. They are used locally and have a specific range.

Class C: **192.168.0.0 - 192.168.255.255**
Class B: **172.16.0.0 - 172.31.255.255**
Class A: **10.0.0.0 - 10.255.255.255**

APIPA (Automatic Private IP Addressing): **169.254.0.0 - 169.254.255.255** /16
- These are assigned whenever a DHCP fails to give a host an IP address, so the host self-assigns an IP address to itself
- It is a fallback mechanism that allows a host to give itself a link-local IPv4 address.
- Doesn't provide a deafult gateway, so this address can't be used for external communication
- Can potentially communicate with hosts that also have an APIPA address. 

By default, these range of IP addresses do not work on the internet and they only work on the **Local Area Network (LAN)**
