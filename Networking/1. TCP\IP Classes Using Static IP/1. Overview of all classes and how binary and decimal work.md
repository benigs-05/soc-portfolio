# IP Address Introduction
Host - Anything that has an IP address 
- IPv4: 32 Bits (DEC) - 4 octets
- IPv6: 128 Bits (HEX) - 16 octets


#### Class A /8
1.0.0.0 - 126.255.255.255 

**Loopback address**

127.0.0.0 - 127.255.255.255
- an IP address that that directs network traffic back to the same host that generated it. It allows a host to process IP traffic internally.
- Let's say we ping 127.0.0.1
- OS generated an ICMP Echo Request
- OS checks and recognizes that it's a loopback destination
- Instead of sending the packet through Ethernet or Wi-Fi interface, the packet is internally processed through the loopback interface (lo)
- OS generated an ICMP Echo reply
- The ping program receives the response
**Can be used to:**
  1. Test the local TCP/IP Stack , can verify that OS can process local ICMP/IP traffic
  2. Communication between applications on the same computer
  3. Testing and isolating network services , a database that listens only on 127.0.0.1:5432. This means that applications running on the same host can connect to it, but external hosts cannot
**Private IP Address**
10.0.0.0 - 10.255.255.255

#### Class B /16
128.0.0.0 - 191.255.255.255

#### Class C /24
192.0.0.0 - 223.255.255.255

#### Class D - Used for multicasting
224.0.0.0 - 239.255.255.255

#### Class E - Used for research and in governments 
240.0.0.0 - 254.255.255.255

- I assigned them with different static IP addresses (Static IP addresses, are addresses that you assign manually and will stay the same until you change them), but all belonging on the same network.
- It's in the same network since they all belong to the same network address. We are using /24 (subnet mask 255.255.255.0), in here the first 3 octets identify the network portion, while the last octet identify the hosts. So all the hosts are on the network 192.168.1.0/24
- /24 here is what we call the CIDR Notation (Classless Inter-Domain Routing), the prefix length which indicates how many bits of an IP address belongs to the network portion.
