Key benefits for using SIEM: 
1. Centralization
	1. Instead of checking logs in different devices 
	2. It allows you to gather all the logs in one place 
	3. Analysts doesn't have to switch systems and just use one platform
	4. Faster
	5. Efficient
	6. Effective
2. Correlation
	1. The ability to link separate events and link them together like pieces of puzzle to form a complete picture. 
	2. Example
		1. You receive an alert from the IDS of an IP that did a port scan
		2. We need to enrich data, who it belongs to, is it a trusted IP, who triggered the activity, Windows Event Logs and Sysmon
		3. Who performed the activity 
		4. Where
		5. Which tools were used 
	3. Helps you decide if it's a true positive or just a noise 
3. Historical Events
	1. Look at past events, not just current activity. 
	2. Helps spots patterns that started earlier but weren't noticed at that time 
		1. Example: User logs in from a different location, we can check if the user has logged from that location before.
