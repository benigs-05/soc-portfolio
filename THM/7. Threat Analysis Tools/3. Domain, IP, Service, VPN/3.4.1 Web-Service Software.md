Web-service software is the program the receives request from browsers and sends back website content. 
- Web service = receives request - sends request 
```
Browser requests /logo.png
          ↓
nginx reads logo.png from the server’s disk
          ↓
nginx sends the image in an HTTP response
          ↓
Browser displays it
```

# Contents of a Website 
- index.html -> page content 
- style.css -> appearance 
- logo.png -> image 

Those files are stored on a computer. But that **doesn't mean that these files are already available to browsers** over the internet

# Web-server's Job
The computer runs a program such as nginx, Apache, or Microsoft IIS 

```
Your browser                         Website's computer
     │                                      │
     │  "Please send me /logo.png"           │
     ├──────── HTTP request ────────────────> nginx
     │                                      │
     │                              Reads logo.png
     │                                      │
     <──────── HTTP response ────────────────┤
     │         containing the image         │
Displays logo                               │
```
```
Client computer                    Web-server computer
192.168.10.20:5435  ──────────────>  192.168.10.50:80
                   HTTP request

192.168.10.20:5435  <──────────────  192.168.10.50:80
                   HTTP response
```
