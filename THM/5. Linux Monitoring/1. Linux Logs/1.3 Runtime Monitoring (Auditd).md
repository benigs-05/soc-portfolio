Over 300 system calls in Linux 


# Auditd 
- A daemon is a program that runs in the background to provide a specific service, usually without someone interacting with it directly 
- Auditd is for runtime monitoring 

Auditd rules can be found in:

```
/etc/audit/rules.d/audit.rules
```



Can be viewed in: 
```
/var/log/audit/audit.log
```
Can view them as is but we can also use: 
```
ausearch : provides readability and supports filtering options 
```

So: 
```
ausearch -i -k proc_wget
where: 
i = interpret values into readable names 
k = search using a particular event
```


where: 
1. Proctitle: shows the process command line 
2. CWD: current working directory 

Remaining two lines show details like:
1. pid and ppid = process ID and parent process ID 
2. auid = the account used to login (locally or remotely)
3. uid = the user who ran the command 
4. tty = session identifier 
5. exe = path to the executed binary 
	1. key = for filtering events q
