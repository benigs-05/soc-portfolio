# DHCP (Dynamic Host Configuration Protocol)
- A network protocol that uses UDP port (67/68)
- Used to dynamically assign IP addresses along with the necessary configurations that a device might need (ie. IP address, subnet mask, DNS server, Gateway etc.).
- IP addresses are assigned through leases, which means that they are **allocated for a specific time** before being renewed.

Let's start with **how we can assign IP address through the use of DHCP servers** on Packet Tracer.

Without DHCP, we would need to manually assign IP addresses to each of our host. 

With DHCP we can allocate IP address by specifying a pool of IP addresses that our hosts can use. We can do this by configuring our DHCP server.

In here we can see a few options/configurations that are assigned to hosts when they request an IP:
1. Pool name, can help identify **where that pools belong in the network.**
2. Default Gateway
3. DNS server
4. Start IP Address
5. Subnet Mask
6. Maximum number of users, is used to **conserve and specify how many IP addresses** we can use in a given network.

Configuring it we get: 
1. Pool name, **OfficeLAN**, only an identifier and isn't passed 
2. Default Gateway, **192.168.1.254**
3. DNS server, **8.8.8.8**
4. Start IP Address, **192.168.1.1**
5. Subnet Mask, **255.255.255.0**
6. Maximum number of users, **10**. This means that from **192.168.1.1** it'll only consume IP addresses up to **192.168.1.10**

After that we need to configure an IP address for our server? 
- Why do we need to even if they're in the same network already?
- Why do we need to even if the discovery doesn't require the server's IP?

**The process:**
1. The initial discovery doesn't require the server's IP **(D)**
  - Initially since a host doesn't have an IP address yet it broadcasts a DHCP Request
    - SRC IP: 0.0.0.0 Broadcast address: 255.255.255.255
    - In our network, it'll receive the broadcast because it's in the same broadcast domain
2. The DHCP server responds **(O)**
  - The server responds with a **DHCP Offer**, that might use broadcast delivery
  - At this stage the server doesn't strictly need a convetional IP address **just to receive the discovery broadcast** and **offer an address**.
  - However, standard DHCP server implementations **have an IP configuration**
3. Why does the server need an IP address?
  - **Server identification**: DHCP message includes a **Server Identifier** that **contains the DHCP server's IP address**.
  - **Lease renewal**: Once a client has an address, it can send unicat DHCP renewal directly to the server.
  - **Network management**: Admins can manage the DHCP over the network
**IN CONCLUSION:**
- It needs an IP since standard DHCP configuration needs an IP to work, and it's replies often have DHCP Option 54, which contains the server's IP address
- I gave the DHCP server an IP address of 192.168.1.1
**Configuring the hosts**
- We need to configure them so that they receive IP configuration through DHCP
- After that, they now can receive their IP address along with their **network configurations**.
