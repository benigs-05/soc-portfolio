
# Linux in Entry Point
- Linux are deployed as:
	- Firewalls
	- Web servers
	- Mail servers
	- Other public-facing servers
- So it can open the door as an entry point to corporate network

# Linux in Espionage
- Targeted by state-sponsored threat groups since they contain sensitive information, use persistence to continually gather data 


# Linux in Ransomware
- Hypervisors as target, if hypervisors aren't secured properly, VMs are at risk
