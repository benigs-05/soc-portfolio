
File paths
- Earliest heuristics to analysts 
- Can reveal patterns 

Paths that might be targeted: 
```
C:\ -> the system drive, can be common for persistence
```

```
C:\Users\Public -> profiles that can enable cross-user access
```

```
C:\Users\Public\Public Downloads -> provides high traffic, that avoids strict monitoring
```

Or for staging patterns: 
```
C:\Windows\Temp -> temporary directories for epehmeral payloads
```

```
C:\ProgramData\ -> writable system paths for steatl persistence
```

Filenames are modified:
```
invoice.pdf.exe -> double extensions
```

```
svchost.exe -> system binary impersonation
```

```
fh&2j1.exe -> high entropy file name, usually phishing
```

```
backup-2300.exe -> blends in with routine files 
```
