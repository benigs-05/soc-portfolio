# Running and Startup Config

1. Running configuration
   - Stored in: RAM
   - Configuration currently beings used by the devices
   - Survives reboot? NO
   - Changes? Applied instantly when configured
   - Command to view: `show running-config`
<img width="570" height="478" alt="image" src="https://github.com/user-attachments/assets/d9924fe6-8d1a-4198-93ad-e28748cc7dda" />


2. Startup configuration
   - Stored in: NVRAM
   - Saved configuration is loaded during startup
   - Survives reboot? Yes
   - Changes? Updates when you save a configuration
   - Command to view: `show startup-config`
<img width="295" height="42" alt="image" src="https://github.com/user-attachments/assets/94055ea2-e48e-4c24-a3bb-4c6a5246714a" />

This happens when we haven't saved anything yet. 

3. Saving the running-config `copy running-config startup-config` or `write memory` (since the memory is the NVRAM)
