# Time Server 
- Time server uses NTP which is port 123
- Used to provide accurate time to other devices on a network
- Synchronizes the devices's system clocks
- Used for log analysis to ensure timestamps across devices are  consistent
- For troubleshooting, helps determine the proper sequence of events
- Authentication methods like Kerberos depends on clocks being synchronized

Example:
Let's say we have 3 devices. 
1. Router
2. Switch
3. 3 Hosts

Since they all have their configurations for their clock, it will be inconsistent. That's where a time server comes in.
