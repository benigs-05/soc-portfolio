# Class A 
1.0.0.0 - 126.255.255.255

**Private IP address**
10.0.0.0 -> 10.255.255.255

**Loopback address**

In class A:

- The Network portion is the first octet **10**.0.0.0
- The Host portion is the last 3 octet 10.**0.0.0**
- A class B is a **/8**
- It has a subnet mask **255.0.0.0**
- It creates more host but less networks in compared to a Class B network
- It has the most number of host available per network with **16,777,214** usable host

Example Class A network: 
Network ID: **10.0.0.0**
Broadcast ID/Address: **10.255.255.255**
Usable hosts: **10.0.0.1 - 10.255.255.254**

Again, this works the same as the previous example is Class B and C. In which: 
1. Changing the first octet will give a different network and won't allow communication in the Data Link layer
2. Changing the last 3 octet will allow communication as they are on the same network.
