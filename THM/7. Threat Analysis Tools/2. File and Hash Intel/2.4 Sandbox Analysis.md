# Sandboxing Limitations 
- False Negatives 
- Missed Detections 
- Incorrect Conclusions 
- Sandbox Evasion Techniques 
	- Payloads designed to detect and evade sandboxes that leads to false negatives 
	- Environment Awareness Check 
	- Anti-Debugging & Anti-Sandboxing Tricks 
- Limited Execution Time and Coverage 
	- Some terminates 2-5, so full coverage cannot be detected 
	- Time delayed attacks will evade detection
	- So cross-reference with other intelligence 
- Encrypted & Obfuscated Traffic 
	- Most sandboxes cannot decrypt SSL/TLS traffic 
	- DNS Tunneling to hide data in queries
- Fileless & Living off the land Malware 
	- Some threats never touch disk 
	- Bypassing traditional sandbox 
	- Uses Powershell and WMI persistence
