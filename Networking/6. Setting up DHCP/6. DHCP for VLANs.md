# DHCP for multiple VLANS

## VLAN (Virtual Local Area Network)
- Before I start configuring, a VLAN is a logical division of a **layer 2 network**.
- **MAIN PURPOSE**: **divide** one physical network into **multiple separate broadcast domains**
  - In simple terms, to **isolate Layer 2 network traffic within the same switch**

# Subinterfaces
- Allows one physical router interface to serve multiple VLANs
- Important in this particular section because we're trying to provide DHCP in VLAN 10 and VLAN 20 using only one router.
**Why do we need subinterfaces?**
- In our network VLAN 10 and VLAN 20 are separate broadcast address
- It solves the problem of, **"How can a router interface act as the gateway for two different VLANs?"**
**How do subinterfaces work?**
  - It divides one physical interface **into multiple logical interfaces**
  - Although there is **one physical Ethernet cable** between a router an a switch
  - The router can **distinguish traffic from the different VLANs** through IEEE **802.1Q VLAN Tagging**

**Configuring subinterfaces**
1. Make sure the link is up `int g0/0` -> `no shutdown`
2. Create the subinterface `interface g0/0.[identifier]`
3. Associate the traffic that's tagged with a given VLAN  with this interface `encapsulation dot1Q {vlan id}`
4. Establish the layer 3 gateway for that specific VLAN `ip address {ip gateway} {subnetmask`
5. **Reminder:** Gateway per VLAN and subinterface is different since each VLAN is assigned with its own IP subnet

# Creating the DHCP server (Can either be the router, a Server within or outside the LAN)
1. Since I'm going to go with using the router as a server
2. Exclude Static IPs `ip dhcp excluded-address [static IP]`, we need to exclude both the gateway for the VLAN 10 and 20
3. Creating a pool for the different VLANs `ip dhcp pool [identifier]`
4. Creating the configurations that needs to be passed:
  - `network [network id] [subnet mask]`
  - `default-router [gateway]`

# Trunking
- Without trunking, an ordinary access port **carries traffic for only one vlan**
- It allows multiple VLANs to share one physical link.
**Configuring the trunk**
1. In the switch, we need to go to the interface connected to the router `int [interface]`
2. Enable trunk `switchport mode trunk`
3. Verify through `show int trunk`
<img width="742" height="256" alt="image" src="https://github.com/user-attachments/assets/7fa50cf0-b331-49d5-9b82-03726e6ac907" />

**Conclusion**
VLAN - Separates a layer 2 network into different broadcast domains 
Subinterface - allows the router to handle each VLAN's Layer 3 traffic separately 

Trunk - allows one interface to carry multiple VLANs
