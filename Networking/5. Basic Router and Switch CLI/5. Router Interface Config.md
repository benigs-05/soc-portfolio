# Interface configuration

For this part, I'm going to focus on basic Interface configuration that's going to be mostly used when it comes to configuring a router. 

<img width="668" height="389" alt="image" src="https://github.com/user-attachments/assets/ac5e0a96-65f2-4889-9c86-62363cbf667f" />

We have this simple network topology.
- The first thing to notice is that initially the **switches are already up**
- Router's link is down

Explanation for why this is:
- This is because switch ports are **generally enabled by default**
- Cisco routers, on the other hands, are often **administratively disabled by default**

Spotting in real life and Cisco Packet Tracer
- Usually, in packet tracer the indicator if a link is up or down can easily be seen via the illustration
- How about in real life?
  - **Physical indicators**: Most devices have LED indicators near their Ethernet port
      - **Green light**: Link is established
      - **Blinking light** - Network activity occuring
      - **No light** - No physical link detected
      - **Amber light** - Varies, can indicate a fault, blocked port or another status
  - CLI Commands `show ip interface brief` or we can focus on a link `show int {interface}`
     <img width="594" height="235" alt="image" src="https://github.com/user-attachments/assets/72419b0e-d720-4474-94c6-adaf2949c121" />
      - **up/up**: Link and line protocol operational
      - **down/down**: Link not operational
      - **administratively down/down**: Interface disabled through configuration
      - **up/down**: Physical connection detected, but line protocol is down
  - Network Monitoring systems
      - Since in huge organizations they don't generally check it manually.
      - So they use monitoring systems
      - SNMP (Simple Network Management Protocol) which is used for managing and giving out status for your networking devices.


   Since we know that from the previous `show ip int br` that the interface G0/0 is administratively down, we can enable it with the command
  `int g0/0` -> `no shutdown` in Global Configuration Mode
