# New User Account 
- If SSH is exposed, attacker might create a new account, add it to a privileged group, and use it for further SSH logins
- Detection is simple since we can track events through authentication logs
	- auth.log
	- Then reconstruct the whole process tree with auditd (ausearch)


# Backdoored SSH keys 
- Backdoor the SSH key of one of the users and use them for future logins instead of a password 
- Hard to know which key is the backdoor key 


By default authorized SSH public keys are stored in EACH USERS /.ssh/authorized_keys
- Best method is to monitor changes to these files using auditd
```
ausearch -i -f /.ssh/authorized_keys
```


echo command will be logged as BASH
