## The Transport Later protocol has 2. It's either UDP or TCP
1. TCP - connection-oriented, reliable,ordered delivery
2. UDP - connectionless, fast, doesn't guarantee delivery 

## Ports 
- Port numbers are used to identify a connection endpoint to a specific service. 
- In the connection we can see that the endpoint machine has an IP address of 192.168.1.1, which is our server and has a port number 80. 
- The foreign address has an IP of 192.168.1.3 and a port of 1026
- So why is the foreign address, the host client trying to access the service has a port of 1026 and not 80?
- Because in a connection the client typically uses a temporary port called an **ephemeral port**, while the HTTP server listens to its corresponding **TCP port 80**
- System ports: **0 - 1023**
- User ports: **1024 - 49151**
- Dynamic and/or private ports: **49152 - 65535**
- IP + Port is what we call a **socket**
## Netstat 
- Is a command line utility used for displaying information about a the host's network connections, listening ports, and network protocols
- Netsat helps troubleshooting by create a view of the network communication endpoints and connection states of a device.
