# Dynamic NAT (Temporary one-to-one mapping)
- Just like Static NAT, it maps one private IP to one Public IP, but it's just temporary.
- For example, we have 10 host machines, but only 3 public IP address are available for NAT
  - It creates a pool **(211.0.10.1 - 211.0.10.3)**.
  - So instead of permanently assigning one public IP to each computer, the router decides and automatically assigns an available public IP
  - **Problem:**
    - Let's say 3 hosts are already using the public IP address, what happens?
    - The router cannot create another translation
    - Host must wait until an address becomes available, or traffic from that host will fail to be translated

# How do we configure it? 
<img width="941" height="512" alt="image" src="https://github.com/user-attachments/assets/5fe74c96-3b78-40f5-8d17-98c6c282ad58" />

Using our template again, the process is less compared to how Static NAT is. 
1. We have to first create a pool, this is assuming that we've already specified which interface is the **nat inside and nat outside**
<img width="512" height="31" alt="image" src="https://github.com/user-attachments/assets/3a3c6672-b46f-424b-91dd-e558ec11ffbd" />

`ip nat pool {name of the pool} (starting range) (last address) netmask (subnetmask)`

- ip nat: configures NAT
- pool: creates a pool
- netmask: specifies the subnetmask of the public IP

2. Next is we need to create an access list on which hosts are allowed for NAT translation
`access-list 10 permit 192.168.1.0 0.0.0.255`
- access-list: create an ACL entry
- 5: is an identifier within the standard range <1-99>
- permit: permits the specified source
- 192.168.1.0: Network being permitted
- 0.0.0.255: Wildcard identifying which bits can vary
  - 0 means the corresponding bits must match
  - 1 means the bits can be anything
<img width="393" height="28" alt="image" src="https://github.com/user-attachments/assets/fb8653fb-a4f4-4fb6-a447-b1a7acaf9291" />

3. Lastly, we need to link the pool (D-NAT) to the access-list (5)
`ip nat inside source list {acl identifier} pool {name of pool}`

<img width="363" height="29" alt="image" src="https://github.com/user-attachments/assets/e6f0fdee-0f1b-4716-950b-a17aaebae08b" />

- inside source: translates source IP addresses
- list 5: uses the ACL identifier to identify which private IPs are allowed for NAT
- pool D-NAT: uses the pool of public IP from the pool named D-NAT

### Use cases for Dynamic NAT
- Dynamic NAT, compared to the other 2 (Static NAT, PAT), is less used.
- It's still used rarely when organization need temporary one-to-one mappings from a pool of addresses.
