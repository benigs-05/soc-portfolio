# What is a MLS (Multi-Layer Switch)
- A layer 3 networking device that supports both **switching and routing**
- By default it functions as a switch
- To enable it, we need to use the command `ip routing`

Another function is that MLS usually supports **PoE (Power over Ethernet)**
