# Logs normalization
- Different formats 
	- JSON
	- XML 
	- Plain Text 
- Each system logs in different ways 

So the idea is to convert all these formats into a single, consistent structure so logs are easier to work with 

So instead of different log formats 
	Everything is normalized into a single consistent format for easy viewing and correlation.
