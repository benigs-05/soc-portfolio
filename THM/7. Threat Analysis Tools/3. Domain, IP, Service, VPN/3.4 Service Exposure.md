Exposed services from an IP 

Helpful in 2 ways: 
1. Victim's IP address 
	1. Let's us understand how the attacker got in
2. Attacker's IP address
	1. if it runs outdated RDP exposed, the host was likely compromised and is being used as a jump point by attackers 

# Tools 
https://www.shodan.io/ 
- Powerful reconnaissance tool for IP addresses 
- Open ports 
- Running services 
- System Configurations 

- Port 80 - HTTP
- nginx - web-server software responding 

Censys Search
https://platform.censys.io/ -> good alternative to Shodan
- Shows exposed services even on non-standard ports 



# TLS Certificates 
TLS certificates can be an indicator for IPs that expose HTTPs services 
- https://platform.censys.io/
- https://www.sslshopper.com/ssl-checker.html

Information too look at: 
1. Issuer: Self-signed certificate can be a strong indicator to investigate it 
2. Validity: Newly-created and long-lived certificates can also be an indicator 
3. Subject - Domain names the certificate covers. Might point to different websites
