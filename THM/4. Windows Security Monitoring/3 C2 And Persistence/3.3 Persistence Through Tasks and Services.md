# Services 
- Create a windows service 
```
sc create "BadService" binpath= "C:\malware.exe" start=auto 

sc create - registers a new service, "BadService" is the name 
binpath = speicifies the program it should launch 
start=auto - automatic startup after boot
```
- Launch of sc = Sysmon/1
- Service creation = Security/4697
- After that, with no account specified to run it, LocalSystem runs it, a highly privileged account

# Detecting Services
Three ways to detect it in logs:
1. Detect the launch of sc.exe create via Sysmon 1
2. Detect service creation Security 4697 or System 7045 (new service was installed)
3. Detecting suspicious processes with a **services.exe parent process**



# Tasks 
- Creates a scheduled task that runs after an OS startup 
```
schtasks /create /tn "BadTask" /tr "C:\malware.exe" /sc onstart /ru System

schtasks /create - creates a new windows scheduled task
/tn "BadTask" - task name
/tc - specifies what program it will execute
/sc - triggers on startup 
/ru - selects the highly privileged LocalSytem account
```
- Launch of schtasks.exe = Sysmon/1
- Scheduled task creation = Security/4698


# Detecting Tasks 
- Much easier to hide
- Detect it in three ways: 
1. Launch of schtasks.exe through Sysmon 1 
2. Detect and analyze scheduled task creation via Security 4698
3. Detect suspicious processes with svchost.exe [...] -s Schedule as parent
