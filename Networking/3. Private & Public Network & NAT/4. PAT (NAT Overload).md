# PAT (Port Address Translation)/(NAT Overload)
- This allows multiple hosts with private IP address to share a singular public IP address **BY USING DIFFERENT PORT NUMBERS**
- If we have 3 hosts:
  - 192.168.1.1:5001 -> 211.0.10.1:10001
  - 192.168.1.2:5001 -> 211.0.10.2:10002
  - 192.168.1.3:5001 -> 211.0.10.3:10003
  - Port translation can theoretically support 65,000 (65,536) port mappings per public IP

- It's mapped to a singular public IP address and their identifier is a port.

# How do we configure it? 
1. Again, assuming we have already configured `ip nat inside` and `ip nat outside`. We are to create a pool again
`ip nat pool PAT 211.0.10.1 211.0.10.1 netmask 255.255.255.0`
<img width="505" height="24" alt="image" src="https://github.com/user-attachments/assets/2d77bc99-877c-423a-931a-a82a78a95258" />

2. Now, create an access-list again
`access-list 6 permit 192.168.1.0 0.0.0.255`

<img width="397" height="30" alt="image" src="https://github.com/user-attachments/assets/548ce299-1411-4823-9064-2083143076e5" />

3. Link + the additional command `overload`
`ip nat inside source list 6 pool PAT overload`
