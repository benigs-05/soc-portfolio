# DHCP Relay

Let's talk about what a **DHCP relay** is before I move on to configuring a Cisco Router as a DHCP relay. 
- Earlier, we've used a DHCP on the same network.
- Configured a router to act as a DHCP between two different networks in two different interfaces. Technically the same as a switch with a DHCP server.
- A DHCP server or an interface from a router might receive the DHCP discover, but **won't forward it in other networks.**
- **DHCP Relay**: is a feature that allows devices to obtain IP addresses from a DHCP server that is located on a **different network or subnet**.
- **DHCP Relay forwards the request** as a separate DHCP message to the DHCP server, including the giaddr (Gateway IP address) **based on the INTERFACE NOT THE HOST**
- A **DHCP server** identifies the client's subnet using the giaddr field, and **selects the appropriate DHCP pool.**


# Configuring a DHCP Relay on a router 

Consider this network infrastructure: 
<img width="1135" height="527" alt="image" src="https://github.com/user-attachments/assets/b43b9f95-465d-4cc8-bc85-519ba79ba12f" />


It's divided into **3 different networks**:
1. Network: **192.168.1.0/24**
   - 2 Hosts - **Running on DHCP**
   - Switch **connected to G0/1**
   - Gateway Address: **192.168.1.254**
   - Subnet mask: **255.255.255.0**
2. Network: **192.168.2.0/24**
   - 2 Hosts - **Running on DHCP**
   - Switch **connected to G0/2**
   - Gateway Address: **192.168.2.254**
   - Subnet mask: **255.255.255.0**
3. Network: **192.168.3.0/24**
   - **1 DHCP Server**
   - Switch **connected to G0/3**
   - Gateway Address: **192.168.3.254**
   - Subnet mask: **255.255.255.0**

Now in the DHCP server, we need to create as many pools as we need, in my case I need to create **one for the 192.168.1.0/4 network and one for the 192.168.2.0/24 network**.

- I need to be inside of the interface of the network that needs DHCP. `int g0/1` -> `ip helper-address {DHCP server IP}`
- Then to `int g0/2` -> `ip helper-address {DHCP server IP}`
