```
Cyber Threat Intelligence (CTI) is information about cyber threats that has been collected, analyzed, and given context so people can make informed security decisions
```

# What does threat intelligence provide
- Provides context that helps an analyst decide which of those hundreds of alerts REPRESENT DANGER 
- Provides reliable context 
- Removes guess work from SOC to calculated action


Threat Intelligence answers:
- Who or What is on the other end of this alert indicator?
- What was their behavior in the past 
- How does my organization respond?
- What should I do about it right now?
# From Raw Data to Usable Intelligence 

Data - an unprocessed observable
```
192.168.10.1:443 -> Capture the artifact
```

Information - Data plus factual annotation
```
IP registered to Hetnzer, first seen 2025-06-07 -> Record these attributes
```

Intelligence - Analyzed information that answers `so, what?`
```
IP belongs to the current Bumblebee C2; block immediately -> escalate or suppress
```

# L1 Analyst Job
- Make the artifact usable, enriching them with information until they become intelligence. 
- This process is called enrichment
	- rapid, methodical lookups of public, commercial, and internal sources that shed light on origin, behavior and relevance


# The Three Labels 
1. Indicator of compromise -> Evidence of a breach, like a C2 address in logs 
2. Indicators of attack -> A malicious action, like a PowerShell launching an unknown service
3. TTP -> Attacker's methodologies expressed through MITRE ATT&CK IDs and Description
