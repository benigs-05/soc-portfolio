# How do we setup Passwords and Secrets

Password and Secret are used whenever the User is trying to use the Privileged EXEC Mode. 
- This is setup in Global Configuration Mode
- Both will require you to enter a password BUT the difference is that `enable password`, stores the value as plaintext. `enable secret` stores the value as a hash.
- And when you enable both of them, `enable secret` will override `enable password`

## Setting it up
1. We need to be in Global Configuration mode. If in user `enable` -> `configure terminal`. If in privileged EXEC `configure terminal`

## Disabling a configuration

To disable a configuration we can just add a `no` to the beginning of the command minus the value that we inputted. 
The command `no enable password`, disables and removes the configuration
