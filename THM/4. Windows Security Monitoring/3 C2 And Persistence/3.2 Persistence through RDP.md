

RDP is breached because of vulnerabilities like a weak password 
- Persistence is created through creating additional vulnerability (backdoor or a web shell)
- Creating a new user and make it an admin and use it for RDP logins 

Example for creating a new user via powershell or the command line 

```
net user "user" "password" /add

$password = Read-Host "Enter pass" -AsSecureString (declares and inputs)
New-LocalUser "user" -Password $password
```

**Adding them to local group**
```
net localgroup Administrator "user" /add
Add-LocalGroupMember "Administrator" -Member "user"
```

**How do you detect created backdoored users?** 
1. Windows Event ID 4720 (Account created), the investigate:
	1. Who created the account, can person confirm 
	2. What is the source IP and time of the creator's login? Is it expected?
	3. Any other suspicious events can you see in the creator's sessions?
2. Windows Event ID 4732 (User was added to a security group)
	1. Usually through Remote Desktop Users or Admin groups
3. Windows Event ID 4724 actors might reset passwords of old accounts or unused accounts 
4. 4624 (Successful logon) and 4625 (Failed logon)
