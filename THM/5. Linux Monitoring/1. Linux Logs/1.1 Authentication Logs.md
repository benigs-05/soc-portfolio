# Login and Logout Events 

Linux also logs successful logons and logoffs

Example to search for is: This can be for both CRON and ssh logins 
	Why can cron be used to login? 
		For scheduled jobs, it opens a session for that account, which runs the command for that cron job under a user account. Then it closes after the job is finished 
```
cat /var/log/auth.log | grep -E 'session opened|session closed'
```
Though this can differ since different organizations might have different ways to format their logs 

```
cat /var/log/auth.log | grep "sshd" | grep -E 'Accepted|Failed'
```
This is for looking at logs wherein successful and failed SSH logins occured 


# Miscellaneous Events 

```
cat /var/log/auth.log | grep -E '(passwd|useradd|usermod|userdel)\['
```
passwd : change password
useradd : add user 
usermod : moidfy user 
userdel : delete a user 
`\[`- for indicating the process ID since we are referring to specific processes that actually managed users

# Commands Run with Sudo 

```
cat /var/log/auth.log | grep -E 'COMMAND='
```

COMMAND = for sude entries
