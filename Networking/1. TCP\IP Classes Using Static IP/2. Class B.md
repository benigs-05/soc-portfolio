# Class C (192.0.0.0 - 223.255.255.255)

## Public IP address 
- 192.0.0.0 - 223.255.255.255
- IP address that is used to route externally.

## Private IP address 
- 192.168.0.0 - 192.168.255.255
- IP address that is used internally.

## Network Portion and Host Portion
- In a Class C network or /24 network. We have the subnet mask 255.255.255.0

The first 3 octet (**255.255.255**.0) represents thet Network portion , while the last octet (255.255.255.**0**) represent the Host portion. 
Example: 
**192.168.1**.1/24 -> is the network portion.
192.168.1.**1**/24 -> is the host portion.

There are also 2 addresses within a network that's used for identification, that's the NID (Network ID) and the BID (Broadcast ID).
- Network ID (NID), this address identifies the network that an IP address belongs to, this is always the first address 
- Broadcast ID (BID), this address allows a host to send a packet to all hosts in a given subnet, this is always the last address

In the example above, the NID and BID is based on the subnet mask that we are using. In this case we are using 255.255.255.0.
- This means that there are 255 address that can be used in a network.
- 2 of those address are reserved
- Which leaves us with 253 usable address.

In our example, 192.168.1.1/24 

NID = **192.168.1.0**

Usable IP address for hosts = **192.168.1.1-254**

BID = **192.168.1.255/24**

## What is ping? 
- A diagnostic utility used to test whether one host can reach another host in an IP network.
- It uses the ICMP (Internet Control Message Protocol), this is a network-layer protocol (Layer 3) that is used to communicate diagnostic information and network errors
- So why does it still work even though this is a Layer 3 protocol, and the hosts are communicating through a Layer 2 switch without a router?
-   Layer 3 communication doesn't always necessary require Layer 3 routing, since Layer 3 actually determines whether a destination is local or remote. If local, it can send directly over Layer 2
-   Since it knows that the IP trying to be reached belongs on its local network, it can deliver the packet without using a router.
-   It uses MAC address, if the MAC address of the destination is unknown ARP is used. 
- It uses 2 ICMP message types:
  1. ICMP Echo request (Type 8) - this is sent by the device initiating the ping
  2. ICMP Echo reply (Type 0) - this is sent by the device responding
 
- How it works?
PC0 -> ping 192.168.1.2 //This is PC1
1. PC0 checks how to reach 192.168.1.2 with its routing information. Since PC1 is on the same subnet it can send the packet directly, but it can also use ARP first to learn PC1's MAC address
2. Once that's learned, PC0 sends an ICMP Echo Request to PC1
3. PC0 measures the time in sending and receiving the reply. Hence the output that we got

32 bytes -> Size of the received ICMP response 
icmp_seq = 1 -> identifies the ping request/reply
ttl=128 -> Time to Live in the received IP packet 
time<1ms -> roundtrip time
