1. We use auditd, ausearch + keys 

```
ausearch -i -k key

-i interpret as readable 
-k for specific key
```

Context of these commands:
1. Web server suddenly spawns `whoami 
2. IT starts looking for secrets like `find or grep`

Flow would be: 
```
ausearch -i -x whoami -> search for discovery command
```

```
ausearch -i --pid num -> search for its parent
```

```
ausearch -i -ppid num -> once the parent is known, check for other child processes 
```
