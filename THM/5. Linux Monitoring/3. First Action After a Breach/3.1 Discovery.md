These are the initial commands that most use when it comes to discovering in Linux 

# OS and Filesystem discovery 
```
pwd -> shows current working directory

ls / -> list contents of root 

env -> displays environment variables, why is it important? reveal current user, working directory, executable search paths, and configuration values

importance of these environments: environments are a collection of variables that gives program information about the system and session. 

gives out the tools installed, custom scripts are stored, whether the system uses unusual directories, which command will be selected first 

example: 
USER=alice
HOME=/home/alice
SHELL=/bin/bash
PATH=/usr/local/bin:/usr/bin:/bin

colon is a separator 

uname -a -> displays kernel and system information

lsb_release -a -> displays linux distribution information

hostname -> display system hostname
```

# Users and Groups discovery
```
id -> Shows the current user’s identity, UID, primary group, and supplementary groups 

whoami -> username of the current process

w -> shows users cuurently logged in, terminal, login times, what they are doing

last -> reads login history, previous session, login/logout times

cat /etc/sudoers -> displays main sudo policy file

cat /etc/passwd -> displays local account information\
cat /etc/shadow -> displays password and user
```

# Process and Network Discovery
```
ps aux -> shows current running processes and who is running it

top -> shows processes running, like task manager

ip a -> display network interface

ip r -> displays routing table 
 
arp -a -> displays arp cache 

ss -tnlp -> displays listening tcp socket and processes using it. Identifies processes connected to remote systems

netstat -tnlp
```

# Cloud or Sandbox discovery
```
systemd-detect-virt -> checks whether running inside a virtual machine or container

lsmod -> lists current Linux kernel modules, kernel features, and drivers active

uptime -> shows how long the systems are running and load average

pgrep -a -f name like 'wireshark|tcpdump|falcon|defender' 
```
