Two main sources for Linux logs: 
1. auth.logs
	1. Authentication related activities 
	2. Logins/logouts
	3. Sudo usage 
	4. Spotting failed login attempts, unauthorized access, or privilege escalation

# Authentication Logs 
- Helps us understand how users interact with the system
	- Privilege escalation
	- Login attempts 

**Unusual Login Attempts**
```
index=linux source="auth.log" *ubuntu* proccess=sshd
| search "Accepted password" or "Failed Password"
```


**Privilege Escalation Attempts**
```
index=linux source="auth.log" *su*  
| sort + _time
```



This just shows events that a user accessed something or had access to something using root/su


# System Logs 
- Capture events related to services activity, system restarts, and crons 
- Behavior 
- Persistence 
- Privilege Escalation

**Persistence Mechanisms**
This example follows the above example where a user has successfully swapped to root/su 
```
index=linux sourcetype=syslog ("CRON" OR "cron")  
|  search ("python" OR "perl" OR "ruby" OR ".sh" OR "bash" OR "nc")
```
