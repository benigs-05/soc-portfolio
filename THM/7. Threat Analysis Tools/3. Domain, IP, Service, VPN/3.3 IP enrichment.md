# Autonomous Systems 

- Collection of IP prefixes under an organization
- Each AS is assigned a unique number (ASN)
- https://bgp.tools/ -> comprehensive info about AS and its purpose 
Like: 
**Residential ASNs** -> Indicate VPN usage or compromised user devices
	Example:  AS124888 (Vodafone)
**Server Hosting**: The most risky role, as it is often used by adversaries to distribute malware.
	Example: AS215439 (PLAY2GO)
**Cloud/CDN ASNs**: Used by both legitimate services and adversaries, needs deeper analysis.
	Example: AS16509 (Amazon AWS)

# Geolocation IP 
- Geolocation enrichment compliments ASN
- Useful for anomalous logins -> user logs in from a different country, suspicious
- https://ipinfo.io
- https://iplocation.net
- provides approximate country 
- city-level accuracy is unreliable 
- network analysis
	- If it's a European company, a traffic to a different country is suspicious
