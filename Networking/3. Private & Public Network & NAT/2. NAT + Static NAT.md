# NAT (Network Address Translation)
- This is used to allow a router or firewall to **translate one IP address into another IP address.**

Example:
- We have 4 hosts that are all connected to the internet using one router.
  - PC1: 192.168.1.1
  - PC2: 192.168.1.2
  - PC3: 192.168.1.3
  - PC4: 192.168.1.4
- But the ISP (Internet Service Provider) only gave us one public IP address, like **211.0.10.5**
- **NAT** answers the question, _"How can all four hosts access the internet using that one given public IP?"_

## How does NAT work?
<img width="968" height="519" alt="image" src="https://github.com/user-attachments/assets/1b9e98e5-9214-4996-af75-d01118c343be" />

Let's say we have this network where:
1. **192.168.1.0/24** is the _internal network_
2. **Router2** is our _internet edge router_
3. **211.0.10.1** is the _public-side IP assigned by the ISP_
4. **Switch3** is a _simplified external network segment_
5. **Server1 and Server2** are _publicly accessible internet services_
6. External servers are on the same subnet as the router's outside interface, which the Public IP being used by the internal network is also on to avoid complexity.
7. This simplifies how NAT work, by showing how private network communicates with an external network through address translation.

### So how does it work? 
1. Let's say PC10 sends a packet. This will have a source IP of **192.168.1.1**
2. The router receives the packet and translates the source IP to its given public IP, which is **211.0.10.1**
3. The router forwards the translated packed to the website, which in this case is **211.0.1.55 or 211.0.1.44**
4. The website responds to the public IP which is **211.0.10.1**
5. The router **checks its NAT translation** and _forwards the response to PC1_
This can be considered a Static NAT, wherein **one private IP address is mapped to** **one public IP address**

### 1st type of NAT 
1. Static NAT (One-to-One)
  - this NAT maps one private IP address to one public IP address.
  - so if you have 30 machines that needs to connect to the internet, you'll be needing 30 public IP addresses
  - **USED IN** hosts, like servers that need a consistent externally reachable address.

#### Configuring NAT 

1. In our router, we want to enter `enable` (Enters Privileged EXEC Mode, where we can do basic monitoring commands, but less administrative access) and `conf t` / `configure terminal` (Enter Global Configuration Mode, wherein we can modify the router's configuration)
<img width="112" height="29" alt="image" src="https://github.com/user-attachments/assets/dbfe59c1-5fd4-4459-9318-5e19980e4d0c" />

2. We turn on the interfaces, because by default in Cisco Packet Tracer, interfaces are turned off.
  - Given that we have we know that we're using both G0/0 and G0/1 we follow these commands to turn it on
  - `int g0/0` to choose the first link
  - `no shutdown` to turn it on
  - and then we repeat the same process for the other link
  - <img width="620" height="203" alt="image" src="https://github.com/user-attachments/assets/b71841fb-78fb-4840-9b22-9fe3530e0045" />

3. Adding IP address to our interfaces (G0/0 and G0/1) This is for the gateway
  - We first go inside our interfaces `int g0/0`
  - Assign them IP addresses, which is the gateway IP address along with the subnet mask, `ip address 192.168.1.254 255.255.255.0`
  - Then repeat `int g0/1` for our external network
  - `ip address 211.0.10.254`
  - <img width="421" height="64" alt="image" src="https://github.com/user-attachments/assets/36254579-a883-45df-a3cd-39f69b8d6d72" />

4. Specifying which is internal, in this case is G0/1, and which one is external, which is G0/1
  - `int g0/0` and then `ip nat inside` and outside for the external
