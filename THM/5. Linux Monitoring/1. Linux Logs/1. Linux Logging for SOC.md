**Log Format**
- Logged into text files
- Can read any logs via Editors
- Default Linux logs are less structured 

Mostly located at: 
```
/var/log
```


Displays the first 10 lines of /var/log/syslog : To see the last 10 use tail instead of head 
```
cat /var/log/syslog | head

cat - reads the file and outputs the content
```
Usually where it's stored, but it an be changed 


# Filtering Logs 
```
cat /var/log/syslog | grep CRON
```
grep - for searching a pattern 
grep -i: ignore capitalization
grep -F: search for literal text 

CRON - a Linux service that runs scheduled jobs automatically 

# Discovering Logs 

```
**ls -l /var/log**
```
ls -l - lists directory contents, while using the long detailed format



```
grep -R -E "auth|login|session" /var/log
```
- -R - search inside of subfolders too that are within /var/log
- -E - let the pattern use special matching rules - let's us use |
