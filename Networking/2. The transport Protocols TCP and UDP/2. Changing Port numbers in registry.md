# Changing Port Numbers 
- To change the port numbers, we can do this by going through the registry.

1. Simply type `regedit` in run. And let's say we want to change the port number of RDP

<img width="460" height="244" alt="image" src="https://github.com/user-attachments/assets/277a2a1a-9ea5-42bc-8111-f77201b25789" />

2. Expand "HKEY_LOCAL_MACHINE" -> "SYSTEM" -> "CurrentControlSet" -> Control -> "Terminal Server" -> "WinStations" -> "RDP-Tcp"
<img width="670" height="540" alt="image" src="https://github.com/user-attachments/assets/ff0a9f06-d7de-49e0-8e56-af202181c645" />

And then look for "PortNumber" 
<img width="629" height="421" alt="image" src="https://github.com/user-attachments/assets/727fcd43-1b34-4c5e-b774-f6f9fdb3976e" />

And then edit it. For it tot take effect, we just need to restart. 

<img width="513" height="410" alt="image" src="https://github.com/user-attachments/assets/a9a1972c-e227-4d2a-a269-9c360652bc86" />

- Checking via netstat we can see that **from 3389**, which is the default, it has now been **changed to 5555**. 

## Connecting to the machine
<img width="630" height="383" alt="image" src="https://github.com/user-attachments/assets/99a76ef7-148f-40ab-b629-3a371efb72b1" />

- Now connecting via RDP without specifying the new port number will cause it to fail, since by default it connects to 3389 when it's not specified.

<img width="598" height="350" alt="image" src="https://github.com/user-attachments/assets/a8d76676-8b77-407c-9463-0e1db13a065e" />

- That's why wee need to specify 5555 before we can connect.

## Another problem
- The first instance worked because the firewall wasn't enabled in the server.
- Enabling the firewall, by default since RDP is enabled it'll permit the predefined rules for RDP traffic which is 3389.
- That's why we also need to add or change firewall rules to allow 5555 as our RDP
- In practice organization don't really change port numbers, but instead harden the devices. So disabling and blocking unnecessary ports and services, and restricting access to necessary services, along with securing and monitoring those services.
