**Command and Control**
- related to USB worms and Phishing
- How do they do it exactly? 
- How do threats send commands and keep control?

**Attacks without C2**
- Can type commands directly through RDP
- But if detected, this can be closed immediately
- To combat that, actors usually set up a C2 immediately 


**C2 Example**
- In use cases that RDP isn't allowed, they need a process
- That process is through the phishing attachment to establish C2 
- In other cases, attachment won't connect back
	- So it downloads an additional C2 malware and then hide it in a folder (11)
	- Works so if file is deleted, C2 is still established 

**C2 Example Flow**
1. User interacts with a phishing link
2. Downloads it (1:Launches Chrome, 11:Downloads the file, 15:For the Stream)
3. User interacts with it (11:Unzips)
4. User clicks it (1:A powershell might launch, hides the C2 in to something like a /Temp folder)
5. Then it connects to the attacker (22: DNS Query-> 3: Connection)
