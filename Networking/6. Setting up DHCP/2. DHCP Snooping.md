# How can we specify what DHCP server our hosts will use? 
Given a network, let's say that a Rogue DHCP server has been installed by an adversary in a company.
- With this, when a victim receives a network configuration from the Rogue DHCP it can:
  1. Give a configuration pointing to a gateway that's actually the attacker's machine
  2. Give a configuration pointing to an attacker's DNS server
  3. This gives chance for an attacker to redirect or direct requests to malicious phishing websites.

## How can we stop this? 
- With a security feature from the switch called **"DHCP Snooping"**

1. Enable DHCP snooping globally. `ip dhcp snooping`
2. Specify which VLANs it's enabled at. Since by it's by default, every host is in VLAN 1 `ip dhcp snooping vlan 1`
3. Enter the port in which your DHCP server is connected. `int f0/23`
4. Mark that port as the trusted DHCP server `ip dhcp snooping trust`
5. Verify via `show ip dhcp snooping`
