# Configuring DHCP on a router 
- In a small environment like an office for a room. We can configure routers to have DHCP enabled instead of relying on actual DHCP servers which can cost quite a lot of money.

## How to configure routers as DHCP 
Considering this following topology with 2 networks: **192.168.1.0/24** and **192.168.2.0/24**
- Wherein:
  1. G0/1 Gateway: **192.168.1.254**
  2. G0/2 Gateway: **192.168.2.254**
<img width="1071" height="425" alt="image" src="https://github.com/user-attachments/assets/e196a181-ae9c-4b2f-b4b9-a656861a50cc" />


1. Excluding IP addresses that have static IP addresses, in this case our 2 of our gateways. `ip dhcp excluded-address {ip}`
<img width="564" height="61" alt="image" src="https://github.com/user-attachments/assets/e6725317-9ebf-45dc-be18-5e12fc7e0031" />

2. Creating a pool for the networks that need to receive DHCP `ip dhcp pool {pool name}`
<img width="436" height="67" alt="image" src="https://github.com/user-attachments/assets/98ced922-1cac-4758-9a15-29427e5f0b8c" />

3. Configure the pool for the configurations that it will send out.
`network {NID} {Subnetmask}`
`default router {gateway}`
`dns-server {dns server}`
<img width="565" height="104" alt="image" src="https://github.com/user-attachments/assets/3dff6d3a-40d3-4ba1-8e29-0066d6472dfb" />

- For security purposes we can also enable DHCP snooping to only trust the router link
- `ip dhcp snooping`
- `ip dhcp snooping vlan 1`
- `int g0/1` -> `ip dhcp snooping trust`
