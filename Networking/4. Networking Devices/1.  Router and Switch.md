# Difference between a Router and a Switch
## Routers (Layer 3) IP Addresses [Packets]
- In simple terms, they allow communication of different networks.
Sample connections:
1. LAN to WAN
2. WAN to WAN
3. LAN to LAN
4. LAN to MAN
etc. 

## Switch (Layer 2) MAC Addresses [Frames]
- While switches allow the communication of devices within a LAN.
- Where our internal devices connect to.

# Difference between a Hub and a Switch
To understand this, let's build a simple network diagram in Cisco

## Hub (Network is 1 collision domain)
<img width="411" height="462" alt="image" src="https://github.com/user-attachments/assets/a70a9f5e-ca67-4330-b822-2629e781cc87" />

Let's say we have this network for our hub. It has 3 hosts, and 1 server. So what's happening in this network? 

- The bandwidth is shared among the devices in the hub.
  - What does this implicate? Sharing means if hosts simultaneously transfer a collision will be created.
  - If the hub supports 100mbp/s, every host is sharing that
  - The topology itself is one collision domain
 
## Switch (Network is 1 broadcast domain)
<img width="404" height="430" alt="image" src="https://github.com/user-attachments/assets/c41f26dc-c3b8-4f72-b908-3087577cfd96" />

- Now for this network which has a switch, each link will have its own bandwidth.
- If it supports 100mbp/s, every host connected will each have 100mbp/s
- If all hosts transfer at the same time, there is no collision
- Each link has its own collision domain, so it's a **per port basis**
- Modern switches effectively eliminate these collisions because of **full-duplex communication**
  - Meaning both can receive and transmit at the same time
 
- Broadcast domain
  - It's a group of devices wherein each host can receive each other's Layer 2 broadcast frames
  - So **whenever a device sends a broadcast**, _every device within that broadcast domain will receive it._
 
## A switch by default
- All hosts belong to VLAN 1
- All hosts share one broadcast domain
- A broadcast from 1 host, will be received by every other host within that switch\
We can confirm this in cisco by using the command
```
show vlan 
```

<img width="588" height="187" alt="image" src="https://github.com/user-attachments/assets/1dacb2e5-5104-4398-9403-c654cf0bde7f" />

We can see that every interface, by default, belongs to the same VLAN 1, **creating one large broadcast domain**
- Adding VLANs means that a new broadcast domain will also be created.

## What happens when we add another new switch and connect it to the old switch? 
<img width="907" height="461" alt="image" src="https://github.com/user-attachments/assets/f81c4bc2-7730-4c7e-91be-0fad9d4cb5a2" />

How many collision domains are there now? 
- Remember, we need to count all the links. So there are now 7 collision domains

How about the broadcast domain?
- Assuming that they all belong to the same VLAN, then they're still part of **one broadcast domain**.

## Routers break up broadcast domain 
Given this network:
<img width="945" height="430" alt="image" src="https://github.com/user-attachments/assets/a60a17c5-0a02-4a17-b401-fa57d8198028" />
**NOTE THAT A CISCO ROUTER WON'T ALLOW TWO SEPARATE ROUTED INTERFACES TO BE CONFIGURED WITH OVERLAPPING SUBNETS**

- It has 2 switch, and a router in between.
- Both broadcast domain belong in the same network

How many broadcast domain are present? **There are 2** since:
- Even though they are on the same network, a router breaks up broadcast domains.
