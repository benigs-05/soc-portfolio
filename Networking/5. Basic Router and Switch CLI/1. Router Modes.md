## The User EXEC mode 
<img width="141" height="46" alt="image" src="https://github.com/user-attachments/assets/d7c9fc1c-61f0-4b4c-a793-1d755de6144f" />

This mode that's indicated by the name of the router, "Router" and a ">" means that we're in "User Mode".
- This is often times used to display information
- And you cannot configure in this mode

So initially, if we don't know what to do we can just use the command "?" to show the available commands at our disposal. 
<img width="390" height="252" alt="image" src="https://github.com/user-attachments/assets/d12f2875-7f4f-4e78-a1da-d595abf352c9" />

These are the different commands that are available in user mode. 

## The Privileged EXEC Mode 
To get into this mode, we type in the command `enable` <img width="115" height="30" alt="image" src="https://github.com/user-attachments/assets/3ff9f291-e3ae-4086-a386-41586519856d" />
- This mode is indicated by the router name "Router" and the number sign "#"
- This is quite similar to User EXEC Mode, only that it can do more advanced monitoring + administrative commands
- To get out of this mode we can just type the command `exit`

## The Global Configuration Mode 
<img width="415" height="44" alt="image" src="https://github.com/user-attachments/assets/7bff0c53-462f-43c1-9e69-290de0051685" />

To get into this mode we just type the command `configure terminal`
- This mode is what's used to modify the router's configuration
- Usually, we are to configure the different interfaces that are connected to our router, we can view this by either going to Privileged EXEC Mode or typing `do show interface brief `
<img width="568" height="98" alt="image" src="https://github.com/user-attachments/assets/77227273-7275-48ce-a1b1-7d4eff96f0ec" />

- To configure an interface, we must choose that interface first by using the command `interface {interface chosen}`

<img width="179" height="35" alt="image" src="https://github.com/user-attachments/assets/dac6aa3a-650b-4d2f-9d0d-8e289d56c9dc" />

And it'll go into that interface for configuration. 

- There are also mode like the subinterface mode <img width="216" height="34" alt="image" src="https://github.com/user-attachments/assets/d41727ff-1afc-412d-947f-be0c98232c46" />
  - This is used for configuring a virtual interface in a router interface. Wherein 10 is used to identify the subinterface number, which is a **logical interface**
- To get out of this mode we can just type the command `exit` or we can just use "CTRL + Z"
